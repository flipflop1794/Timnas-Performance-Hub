# Timnas Performance Hub V1.10 — faster scrim reports, fixes to existing features

## Faster report entry (Scrim reports tab, every title)
- Required fields first: date, written by, partner, result, what was practised, plan rating, worked/failed, next adjustment.
  Everything else sits under "More details (optional)".
- Quick picks: "Planned today: <partner>" (fills the partner and closes that planned session on save), recent partners,
  quick scores (2-0, 2-1, 1-2...; eFootball also Draw), recent focus and active coaching objectives.
- Plan rating is five tap buttons (1 Far off ... 5 Fully) instead of a dropdown.
- "Copy setup from last report" fills partner, level, format, who played and focus.
- After saving, the setup (time, written by, level, format, who played, focus) stays for the next partner; results and notes clear.
- Drafts are kept on the device while typing (survive leaving the tab or reloading). "Clear form" removes the draft.
- A missing field is outlined in red and focused, so the coach sees what to fix.
- Phone keyboards: number pad for scores and points; bigger tap targets.

## Fixes to existing features (all tabs)
- Dates now follow WIB. Before, anything entered before 07:00 WIB got yesterday's date (scrims, reports, VOD notes,
  rival notes, staff observations, wellbeing day, brief date).
- Typing is no longer wiped when a colleague saves something: shared updates redraw the page but keep what is being typed,
  which details are open, and the cursor position. This applies to every form in the hub.

## Notes
- Drafts are stored only in that browser on that device; they are not shared and not a backup.
- Tests: 82 automated tests pass (docs/TEST_RESULTS.txt).
